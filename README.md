# Gesture-Controlled Virtual Mouse

A computer vision-based project that lets you control your computer's mouse using only hand gestures, using your webcam and the power of MediaPipe and OpenCV.

---

## 🔧 Features

- Control mouse movement with hand gestures
- Click and drag functionality
- Real-time webcam-based input
- Works using OpenCV and MediaPipe
- Hands-free, intuitive interaction

---
